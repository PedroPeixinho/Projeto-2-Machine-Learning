# Projeto final Machine Learning

Este projeto aplica a metodologia **CRISP-DM** a uma base de dados com o objetivo de gerar insights e desenvolver modelos de aprendizado de máquina que apoiem a tomada de decisão.

## 🔄 Etapas do Projeto

### 1. Entendimento do Negócio  
Definição do problema e dos objetivos a serem alcançados com a análise.

### 2. Entendimento dos Dados  
Análise exploratória dos dados, identificação de padrões, outliers e correlações.

### 3. Preparação dos Dados  
Limpeza, transformação e separação dos dados em conjuntos de treino, validação e teste.

### 4. Modelagem  
Treinamento e ajuste de hiperparâmetros dos seguintes algoritmos:
- K-NN  
- LVQ  
- Árvore de Decisão  
- SVM  
- Random Forest  
- Rede Neural MLP  
- Comitê de Redes Neurais  
- Comitê Heterogêneo  

### 5. Avaliação  
Avaliação dos modelos utilizando:
- Acurácia  
- F1-Score  
- Curva ROC  
- Recall  
Inclui comparação estatística entre classificadores.

### 6. Implantação  
Extração de regras com árvore de decisão e sugestões de ações baseadas nos atributos mais relevantes.
